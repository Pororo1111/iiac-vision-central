사용자는 기존 YOLO 박스 초안 + Gemma 태그 선별을 선택했다. 자동 라벨은 `humanReviewed=false`이며 정답 품질을 보장하지 않는다. SAM3와 수동 검토 UI는 사용하지 않는다.

## 이번 재개에서 완료한 내용

- 중앙 배포 계약에 각 활성 단계의 FAILED, APPLYING의 ROLLED_BACK, 종료 보고 재전송·해시 충돌·재진입 차단 검증을 추가했다. 실제 PostgreSQL/API에서 통과했다.
- 중앙 인증·CSRF·장치 분리·이벤트 동시 중복·검색 통합 테스트 4개가 통과했다.
- 원격 IoT의 격리 프록시로 실제 중앙 HTTPS에 503·응답 유실 후 재전송을 검증했다. START/END 각 1건, 테스트 영상 이미지 1건으로 수렴했다.
- 가짜 후보 파일의 배포 조회·다운로드·해시·FAILED 보고·종료 다운로드 409를 확인했다. 실제 모델 로드·GPU 검증은 하지 않았다.
- 검증 장치·중앙 이벤트/이미지/작업·후보/배포/실행·가짜 파일·양쪽 임시 토큰 파일을 정리했다.
- IoT 최종 보고와 Git 확인: `c137838`에 명시적 배포 CLI·중앙 계약 검증이 커밋됐다. Python 테스트 56개 통과. 중앙 변경은 미커밋 상태로 보존했다.
